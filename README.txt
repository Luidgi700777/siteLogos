# LOGOS — Site de apresentação

Site institucional/blog para apresentar a plataforma LOGOS de assessoria de imprensa.

## Como abrir
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Não é necessário instalar Node ou qualquer servidor.

## Estrutura
- `index.html` — conteúdo e estrutura do site
- `style.css` — visual, responsividade e animações
- `script.js` — menu mobile

O layout foi inspirado nas telas do aplicativo enviadas, usando a mesma linguagem visual: azul, branco, cards arredondados e interface limpa.
